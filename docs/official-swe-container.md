# Official SWE-bench container path

The portable verifier must create the Astropy repository inside Linux, rather
than mounting Windows `git worktree` directories. Windows worktree `.git`
files contain host-specific absolute paths and are not valid in the container.

The frozen sample and gold patches are in `research/swe_verified_sample.json`.

For a prepared exact-commit checkout, use `benchmarks/official_slice_runner.py`
to persist the raw test command output.  The runner records execution status
but deliberately keeps `score_eligible=false`; promotion to an official score
requires the benchmark's own test/scorer contract.
The verifier checks the five base commits and gold patch applicability without
calling a model. A successful run reports `checkout_verified` and
`gold_patch_check: true` for each instance. Test execution is a separate gate
because these historical Astropy commits require their original C-extension
build matrix.

Latest local validation (2026-08-09): all five frozen oracle checkouts built
successfully in `xiaopu-swe-astropy:5.0.4` and the modeling separability slice
passed in every case (12907: 11 tests; 13033/13236/13398/13453: 15 tests each).
The persisted records are under `workspace/official_swe/run*/result.json`.
The machine-readable aggregate is `workspace/official_swe/container_summary.json`,
generated by `benchmarks/summarize_swe_container.py`.
This is execution evidence only and is not an official SWE-bench score.
