# Deterministic mechanism check

Run date: 2026-08-09. No model/API calls. Seed 7, 5,000 tasks, cost weight
0.05, risk weight 1.0. These values are generated by the declared synthetic
environment and are not external benchmark results.

## Heterogeneous tasks

| Policy | Expected success | Cost | Residual risk | Objective |
|---|---:|---:|---:|---:|
| direct | 0.6189 | 1.0000 | 0.1605 | 0.4084 |
| always joint | 0.8936 | 5.0000 | 0.0750 | 0.5685 |
| compute only | 0.8484 | 3.1307 | 0.1163 | 0.5755 |
| evidence only | 0.7236 | 2.2796 | 0.0941 | 0.5155 |
| CEGAR-H | 0.8699 | 3.7535 | 0.0867 | **0.5955** |

This passes only the weak mechanism check: a correctly informed joint index
policy maximizes the same objective used to select actions. It would be circular
to present this as empirical method validation.

## Homogeneous negative control

After fixing both difficulty and evidence quality, CEGAR-H exactly reduces to
the compute-only fixed action (objective 0.5748). An earlier version fixed only
difficulty and therefore accidentally retained heterogeneity; that invalid
negative control was discarded.

## What remains falsifiable

- Estimate gains/risks from held-out trajectories rather than simulator truth.
- Evaluate calibration shift and adversarial estimation error.
- Compare the myopic controller with a dynamic-programming oracle.
- Sweep weights and report a Pareto frontier, not one chosen scalarization.
- Run matched external tasks only after the deterministic suite passes.
